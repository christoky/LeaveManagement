# Leave Management System
A web-based leave management system developed using ASP.NET Core MVC and SQL Server to manage employee leave requests, approvals, and leave records.

## Features
* Employee leave request management
* Leave approval workflow
* User and role management
* Leave type management
* Leave status tracking
* Dashboard
* CRUD operations
* Authentication and authorization

## Technologies
* C#
* ASP.NET Core MVC
* Entity Framework Core
* SQL Server
* HTML
* CSS
* Bootstrap
* Git/GitHub

## Project Structure
* **LeaveManagement** – ASP.NET Core MVC web application
* **LeaveManagement.Application** – Application/business logic
* **LeaveManagement.Data** – Data access and database-related functionality
* **LeaveManagement.Common** – Shared models and utilities

## Purpose
This project was developed as a software development project to practice building a database-driven web application using ASP.NET Core MVC, Entity Framework Core, authentication, authorization, and CRUD operations.
